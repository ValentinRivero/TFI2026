## Arquitectura del Proyecto
- **`/backend-django`**: Núcleo transaccional en Python (Django, Django REST Framework, Django Channels + Daphne ASGI).
- **`/backend-node`**: Servicio complementario de eventos y actividad (Node.js + Express).
- **`/frontend`**: Aplicación Web Progresiva (PWA) adaptable con mapa interactivo.
- **`/docs`**: Documentación de planificación, hitos y estado de avance del proyecto.
